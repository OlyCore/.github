# OlyCore

Recursos open source para servidores **MTA: San Andreas**, desenvolvidos pela comunidade OlyCore.

## Repositórios

- [oly_core](https://github.com/OlyCore/oly_core) — núcleo compartilhado da base.
- [oly_loading](https://github.com/OlyCore/oly_loading) — tela de carregamento.
- [oly_inventory](https://github.com/OlyCore/oly_inventory) — sistema de inventário, lojas e armazenamentos.

## Como os recursos funcionam

Os recursos são mantidos em repositórios separados para facilitar a instalação, manutenção e contribuição.

O `oly_core` é a dependência principal. Recursos que utilizam suas funções devem ser iniciados depois dele.

## Instalação

1. Baixe os repositórios necessários.
2. Coloque cada recurso na pasta `resources` do seu servidor MTA.
3. Leia o `README.md` do recurso escolhido.
4. Configure os arquivos locais conforme as instruções.
5. Inicie o `oly_core` antes dos recursos dependentes.

## Contribuição

Sugestões, correções e melhorias são bem-vindas. Antes de abrir uma contribuição, leia as instruções do repositório correspondente e verifique se os arquivos enviados são próprios ou possuem licença compatível.

## Licença e conteúdo de terceiros

Cada repositório informa sua própria licença e suas dependências. Conteúdo pago, protegido ou de terceiros não faz parte da OlyCore e não deve ser redistribuído.

Recursos identificados com `(Trust)` não pertencem a esta organização e permanecem fora dos repositórios públicos.
